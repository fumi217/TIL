## 学んだこと
- **三項演算子**（[MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Operators/Conditional_operator)）
  - `条件式 ? 真の場合の値 : 偽の場合の値`（`if...else`の代わりに使える）

- **アロー関数**（[MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Functions/Arrow_functions)）  
  - `引数 => 式`/`(引数) => {return 式}`（`function(引数){式}`の省略記法）
  - 引数の数や処理の行数によって、`()`、`{}`、`return`も省略可。
    - 引数 0個 or 2個以上…`()`省略不可
    - 引数 1個…`()`省略可（`(name)=>` => `name=>`）
    - 処理 1行…`{}`/`return`省略可
    - 処理 2行以上…`{}`/`return`省略不可

```
引数1個、処理1行
---------------
const name = "bunCHO";
const result = name.split("").map(char => char === char.toLowerCase() ? char.toUpperCase() : char.toLowerCase());

console.log(result.join("")); //=> BUNcho
```
```
引数2個、処理複数行
---------------
const selfIntroduce = (name, birthYear) => {
    const age = new Date().getFullYear() - birthYear;
    return `私は${name}です。\n${age}歳です。`
}

console.log(selfIntroduce("文鳥",2019)); //=>「私は文鳥です。(改行)○歳です。」
```

## 気づき・詰まったこと
- 文字列を配列化後、`for`と`if`で一文字ずつ確認する流れを想定していたが、AIがアロー関数と三項演算子を組み合わせたコードを出力。最初は長い一文で記号も多く「？」となったが、細かく見ていくことで構造を理解することができた。
- `.map()`（[MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/Array/map)）：
  - 今まで配列を整数化するために活用していた（`.map(Number)`）ため、一括で変換されていると勘違いをしていた。
  - 実際は`for`と似た動きをするもの。  
  配列の要素を1つずつ取り出して処理して新しい配列を生成している。`.map(Number)`では、各要素を順番に数値へと変換している。
