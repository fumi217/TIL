## 学んだこと

### クラスとオブジェクト
```
class Bird {
    constructor(name, date) {  // 引数を受け取る
        this.name = name;      // nameプロパティに、引数nameの値を代入(this.プロパティ名 = 引数)
        this.date = date;
    }

    tweet(){
      console.log(`名前は${this.name}です。記念日は${this.date}です。`)
    }
}

const buncho = new Bird("文鳥", 1024);
プロパティ名がkey、引数で与えた値がvalueとなり、オブジェクトが生成されている。
=>  const buncho = {
      name: "文鳥",
      date: 1024
    }
```
- `class Bird {}`：**クラス**（設計図・雛形）
- `const buncho = new Bird();`：クラスから**オブジェクト**（インスタンス）を生成する。
  - 定数`buncho`に、`Bird`クラスのオブジェクトを代入している。
  - 生成時には、`constructor(){}`で設定した処理が実行される。

### クラス内に記載できること
- `constructor(){}`
  - オブジェクト生成時（`const xx = new Class();`時）に実行されるメソッド。
  - `this.プロパティ名 = 値;`で初期値を設定することができる。
    - 例：  
    `constructor(){this.name = "初期鳥";}`  
    `const buncho = new Bird();` => `buncho.name`は`"初期鳥"`
    - プロパティ名はkey、値はvalue。
  - 引数で受け取った値をプロパティに代入すると、オブジェクト毎に異なる初期値を設定できる。
    - 例：  
    `constructor(name){this.name=name}`  
    `const buncho = new Bird("文鳥");` => `buncho.name`は`"文鳥"`

- `メソッド名(){}`（例：`tweet(){}`）
  - `オブジェクト.メソッド();`で呼び出す。
  - メソッド内でオブジェクトのデータを使用する際は、`this.プロパティ名`とする。
  - メソッド内で他メソッドを呼び出す際は、`this.メソッド名();`とする。
