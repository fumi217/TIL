## 学んだこと
- `padStart(長さ, 埋める文字)`で、文字列が「指定した長さになるまで、指定した文字で先頭を埋める」ことができる。

```js
    const n = lines[0];
    console.log(n.padStart(3, " ")); // 文字列型`n`を、`3`文字になるまで、先頭を`半角スペース`で埋めて出力。

    const m = 1;
    console.log(String(m).padStart(3, " "));
```

- 末尾を埋めたい時は`padEnd(長さ, 埋める文字)`が使える。
- 参考：[MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/String/padStart)
