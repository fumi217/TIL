## 気づき・詰まったこと
- 配列の要素や探索対象を数値に変換しておらず、文字列のまま比較してしまっていた。
- 数値化にあたっては`Number()`を使用。今まで`parseInt()`を使用していたため、違いも学ぶ。
  - `Number()`：文字列全体を数値として解釈し、一部でも数値でないものが混じっていたら`NaN`が返る。
  - `parseInt()`：文字列の先頭から数値として読み取れる部分は読み取り、数値として返す。

```
console.log(parseInt("abc123")); //=> NaN 
console.log(Number("abc123"));   //=> NaN

console.log(parseInt("123abc")); //=> 123
console.log(Number("123abc"));   //=> NaN

console.log(parseInt("")); //=> NaN
console.log(Number(""));   //=> 0

console.log(parseInt(42.5)); //=> 42
console.log(Number(42.5));   //=> 42.5
```
