### 継承（クラスとオブジェクト）
- 親クラスのプロパティやメソッドを引き継いだ子クラスを作成できる。
```
class 作成するクラス（子クラス） extends 継承するクラス（親クラス） {}
```
```
class Bird {
  constructor(name, date) {
    this.name = name;
    this.date = date;
  }
  tweet(){
    console.log(`名前は${this.name}です。記念日は${this.date}です。`)
  }
}
class Finch extends Bird {}

const suzume = new Finch("雀", "0320");
suzume.tweet();
// => 名前は雀です。記念日は0320です。
//Finchクラスで何も定義していなくても、Birdのメソッドを継承している。
```

- **オーバーライド**：親クラスと同名のメソッド・コンストラクタを子クラスで定義し直すと、そちらが優先される。
  - `super();`：コンストラクタをオーバーライドする際に必要。
    - 1行目(`constructor(){`の下)に書く。
    - 何をしているか：親クラスのコンストラクタを呼び出している。
    - 親のコンストラクタに仮引数があれば、それも記載する。  
      `constructor(name,date)` => `super(name,date);`
