# 2026年05月21日
## 学んだこと
- **論理演算子**（`||`、`&&`、`!`）
  - ExcelのIF関数で使っていたOR・AND・<>の考え方に近く、理解しやすかった。
  - `||` `&&`：左右それぞれを"ブーリアン型を返す**式**"にすることが大事。
  - `!`（not）：複数条件をまとめて否定する場合は `()` で囲むと読みやすくなる。
- **ネスト（入れ子構造）**
  - `if`の中に`if`を書く構造。
  - 条件分岐だけでなく、今後さまざまな場面で登場する考え方。

## 気づき・詰まったこと・検証
- **ブーリアン型の引数はそのままifに渡せる**
  - `if (flag === true)` と書かなくとも `if (flag)` で判定できる。
- **同じ処理を繰り返さないコードを意識する**
  - 課題では "buncho" や "BUNCHO" というような実引数が渡されていたため、`.toLowerCase()`を使用した。  
    事前に入力値を統一することで別々に判定する必要がなくなり、条件文をシンプルにすることができた。
  - else if を何度も繰り返して似た処理を書いていた際、「オブジェクトでまとめる」という考え方を学んだ。
  - 「とりあえず動くコード」ではなく、「重複を減らす書き方」を意識したい。
- **コードをシンプルに、同じことを何度も書かない**
  - 課題をクリアするにあたり、大文字・小文字の判定を不要にするため、`.toGetLowerCase`を活用した。
  - 何度も`else if`を繰り返し、似た内容の処理をさせるコードを書いた際、オブジェクトという概念を学んだ。
