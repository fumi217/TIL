## 学んだこと
- **配列（Array）**
  - 1つの変数に複数の値を格納できる。文字列・数値など型の混合も可能。
  - 定数名は複数形にすることが多い（例：bird → birds）。
  - インデックス（添字）で特定の要素を取得できる。0番目から数えるという考え方は`slice()`と同じ。
  - 該当のないインデックスを指定するとエラーではなく`undefined`が返る。
```javascript
    const birds = ["buncho", "suzume", "hato"];
    console.log(birds[0]); // => "buncho"
    console.log(birds[3]); // => undefined
```
  - インデックスは直接指定だけでなく、変数や式でも指定できる。
```javascript
    const indexNum = 0;
    birds[indexNum];     // => "buncho"
    birds[indexNum + 1]; // => "suzume"
```
  - 要素の更新・追加が可能。
```javascript
    birds[2] = "karasu"; // hatoをkarasuに更新 ["buncho", "suzume", "karasu"]
    birds[3] = "karasu"; // 新要素として追加    ["buncho", "suzume", "hato", "karasu"]
```
  - **主なメソッド・プロパティ**
    - `push`：配列の末尾に要素を追加。戻り値は配列の新しい長さ（要素の数）。
    - `indexOf`：引数と一致する最初の要素のインデックス番号を返す。存在しない場合は`-1`を返す。
    - `splice`：要素の更新・削除・追加が可能。単一の要素だけでなく、複数要素をまとめて変更することもできる。  
      （他にも`pop` `shift` `unshift` `concat`等あり）
    - `length`：要素数を返す。`()`不要。インデックスの最大値より1大きい値になる。
  - `for`文と組み合わせる時は`i`をインデックスとして使うのが慣例。`length`と組み合わせて全要素を処理できる。

## 気づき・詰まったこと・検証
- **複数要素を一度に更新しようとして失敗**
  - `splice()`を知る前に「複数要素の更新はいかに行うのか」が気になり、`animals[1, 2] = "dof", "rabbit"`という書き方を試したが意図通りに動かなかった。
    - JavaScriptではこの書き方はカンマ演算子として解釈されるため、複数同時更新はできない。
    - `splice`を使うことを把握した。
- メソッドが多くて一度には覚えきれないため、MDNのリファレンスを活用する方針にした。
  - 参考：[Array - MDN](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/Array)
