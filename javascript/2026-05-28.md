# 2026年05月28日

## 学んだこと
- **オブジェクトの実践**
  - 関数の引数にオブジェクトを取り、ドット記法やブラケット記法でプロパティの値を取得する方法を学んだ。
  - ブラケット記法では、式（`obj[array[index]]`）も書くことができ、式の評価結果が`key`として使われる。  
    （[05/27 - 変数を使う方法](JavaScript/2026-05-27.md)）

## 気づき・詰まったこと
- 引数で受け取ったkeyを使う場合、ドット記法では変数として評価されないため、ブラケット記法が必須。
  - `obj.key` → "key"という名前のプロパティを探す。
  - `obj[key]` → 変数keyの値をプロパティ名として使う。

- `obj.array[index]` と `obj[array[index]]` の違い
  - `obj.array[index]`  
    objの中の`array`というkeyを探す → 存在しない`undefined` → undefinedに対して`[index]`を使う → TypeError。
    `Uncaught TypeError: Cannot read properties of undefined (reading '1')`
  - `obj[array[index]]`  
    `array[index]`を先に評価し、その結果をkeyとして使う。
  - ドット記法は固定のプロパティ名のみ。  
    式の結果や変数など、動的に使いたい場合はブラケット記法で記述する。
