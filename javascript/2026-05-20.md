# 2026年05月20日

## 学んだこと
- **条件分岐（`if` / `else if` / `else`）**
  - `if` → `else if` → `else` の順で条件を絞り込む書き方や考え方を理解。

- **文字列プロパティとメソッド**
  - `.length`プロパティを用いた文字数の取得。
  - `.slice(start, end)`メソッドによる特定範囲の文字列抽出。
    - `start` は **0始まり**（1文字目 = インデックス0）
    - `end` は **その手前まで**（`slice(0, 5)` は0〜4文字目の5文字を返す）

## 気づき・詰まったこと
- **`slice` のインデックス**
  - 「1文字目は0」「endは含まない」という仕様に最初混乱した。  
    - `ぶんちょうはかわいい`  
      `０１２３４５６７８９`
    - `${slice(0,6)}！${slice(6,10)}！` ⇒ `ぶんちょうは！かわいい！`
   
- **演算子の省略記法**
  - if文の課題クリアのために多数の関数を書いたが、省略記法が身についていなかったことに後から気づいた。
  - `num1 = num1 + num9`ではなく`num += num9`
