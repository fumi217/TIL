# 2026年05月23日

## 学んだこと

- **スコープ**
  - スコープとは「定義した変数を使える範囲（変数の有効範囲）」。
  - グローバルスコープとローカルスコープ（関数スコープ、ブロックスコープ）がある。
    - グローバルスコープ：プログラム全体の範囲
    - 関数スコープ：関数の内部の範囲
    - ブロックスコープ：`if`文や`for`文などの内部の範囲
  - ローカルスコープからグローバル変数を参照することはできるが、逆は不可（グローバルスコープからローカル変数は参照できない）。
  - グローバルスコープとローカルスコープに同名の変数を定義することは可能だが、ローカルスコープ内で参照するのは、値の近いローカルスコープの変数。
