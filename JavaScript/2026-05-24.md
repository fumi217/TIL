# 2026年05月24日

## 学んだこと
- **スコープの課題実践**
  - スコープの概念を踏まえ、変数の参照範囲に関する課題をクリア。
- **switch文**
  - 条件分岐に用いる。ifと違い、**値の一致のみ**を判定する（比較演算子は使えない）。
  - `case 値: 処理; break;` という構造。どれにも当てはまらない場合は `default:` で処理する。
- **while文**
  - `while(条件式){ 処理 }` の構造。条件式がfalseになった時点で終了する。
- **for文**
  - できることはwhile文と同じだが、よりシンプルに記述できる。
  - `for (変数定義; 条件式; 変数の更新) { 処理 }` の構造。
  - `if`と組み合わせることもできる。

  - 概念としてぼんやり理解していたクロージャを、スコープに関する課題を解く中で実践。
