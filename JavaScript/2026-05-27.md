# 2026年05月27日

## 学んだこと
- **オブジェクトの構文**
  - `const 変数 = {};` と書く。関数やif文と異なり、`{}` の後に `;` をつける。
  - `key: value,`のペアをプロパティと呼ぶ。
  - 順序付け（インデックス付与）されない。
  ```
  const myProfile = {
    name: "fumi",
    love: "buncho"
  };
  ```

- **valueの取得方法**  
  valueを取得する方法は3つある。
    - **ブラケット記法**  
      `object["name"]` keyは文字列のため、""が必要。

    - **ドット記法**  
      `object.name` ""は不要。

    - **変数を使う方法**  
      `const key = "name";` `object[key]`

- **プロパティの追加・更新**  
  上記3つの記法を活用して、プロパティを追加・更新することが可能（ここではドット記法で記載）。
  - 追加：`object.newKey = newValue;`（例：`myProfile.live = "Japan"`）
  - 更新：`object.existKey = updatedValue;`（例：`myProfile.love = "buncho!!!"`）

## 気づき・詰まったこと・検証
- ブラケット記法で `key`を`""`で囲わずに書くと変数として解釈されるため、変数未定義でerrorになる。
  - 変数がない → error（そもそも参照できない）
- 存在しないkeyにアクセスすると、errorではなく `undefined` が返る。
  - keyがない → undefined（オブジェクトは存在するし処理できる、が、そのkeyはない）
