# 2026年05月19日
## 学んだこと
- **比較演算子**
  - `>` `<` `>=` `<=`：左右の数値の大小を比較。結果はブーリアン型で返る。
  - `===`（厳密に等しい）/ `!==`（厳密に等しくない）：値だけでなく型も比較する。
  - `==`：データ型が異なっても値が同じならtrueを返す。実務では`===`をほぼ使う。
    - ※大文字・小文字は区別する。（`AbC` == `aBC`はfalse）

- **演算子の省略記法**
  - `num = num + 5` → `num += 5`（`-` `*` `/` `%` も同様）

## 気づき・検証
- **`;`を抜かさない**
  - 今は動いているけれど、予期せぬバグの原因になる可能性がある。「ここが文末である」としっかり伝えること。
  - 日本語の「。」感覚でつける習慣をつける。
- **`let`は変数、`const`は<ins>定数</ins>**
- **余りの復習**
  - 余りとは、割り切れずに残った値のこと。7 ÷ 2 の余りは1（3個ずつ配ると`1つ`余る））
  - 偶数・奇数の判定：`num % 2 === 0` で余りが0かどうかを確認する。
