## 学んだこと
- **.tsx**：TypeScriptとJSXを組み合わせたファイルの拡張子。
- **JSX**（JavaScript XML）：JavaScriptの中にHTMLに似た記法を書ける拡張構文。ブラウザが直接解釈できる標準の文法ではない。
- **index.html / main.tsx / App.tsxの役割**
  1. `index.html`：`<div id="root">`と`<script src="main.tsx">`だけを持つ空の器。
  2. `main.tsx`：htmlに呼び出され、「`App`を`#root`に描画」とReactに指示。
  3. `App.tsx`：中身（`Hello React`）が`div(#root)`に描き込まれる。

```
【App.tsx】の内容
------------------
import "./App.css";
 
function App() {
  return (
    <>
      <h1>Hello React</h1>
    </>
  );
}
 
export default App;
```

## 気づき・詰まったこと1
チュートリアル通りに各ファイルを書き換えたが、`index.html`をLive Serverで開いても、Chromeへ直接ドラッグしても、`Hello React`が表示されなかった。コンソールには以下のエラーが表示された。

> Failed to load module script: Expected a JavaScript-or-Wasm module script but the server responded with a MIME type of "application/octet-stream".

### 原因
当初は「コードのコピペを間違えたのでは」と考えたが、原因は実行環境にあった。

- ブラウザは`.tsx`をそのまま実行できない。`.tsx`をJavaScriptに変換する工程が必要だったが、Live Serverでは、それができていなかった。
- ドラッグアンドドロップで開いた場合は、ブラウザのセキュリティ制限によりブロックされていた。

### 解決までの流れ
- `npm install` → `npm run dev`を実行。ターミナルに表示されたURLへアクセスしたところ、正しく`Hello React`が表示された。

> 関連：[React公式 - JSXでマークアップを記述する](https://react.dev/learn/writing-markup-with-jsx) / [Vite公式サイト](https://vitejs.dev/)

### AIからの補足事項
- **Vite**（`npm run dev`）：`.tsx`（TypeScript＋JSX）をブラウザが実行できる素のJavaScriptへ変換しつつ、開発用サーバーを起動するツール。`main.tsx`や`App.tsx`を読み込み → TypeScript/JSXを変換 → `http://localhost:xxxx`で配信、という流れをリアルタイムで行っている。
- **Live Server**（VS Code拡張機能）：フォルダ内のファイルをそのまま返すだけの静的ファイルサーバー。変換機能を持たない。
- **`npm install`**：`package.json`に記載された依存パッケージ（Viteなど）を`node_modules`にダウンロードする作業。未実行だとVite自体が手元に存在しない。

## 気づき・詰まったこと2
### 詰まったこと1を解決後の疑問
> 毎回、ターミナルで`npm run dev`と打つ必要があるのか？

`npm run dev`でサーバーを起動すれば、編集・保存のたびにコマンドを実行する必要はない。  
起動後は`.tsx`を編集して保存すると、ブラウザは自動で更新される。

再度コマンドが必要になるのは、以下のような場合。
- ターミナルを閉じた。
- PCを再起動した。
- サーバーを Ctrl + C などで止めた。

### リアルタイムで反映されない問題の原因と解決策
> `App.tsx`を`<h1>Hello React</h1>`から`<h1>Hello React!!</h1>`に変更しても即時反映されない。

#### 原因
WSLでViteを実行している環境なのに、プロジェクトはWindows（Dドライブ）に置いていた。ファイルの変更が検知されず、自動更新されていなかった。

#### 解決までの流れ
- プロジェクトをWSL（/home/...）に移動。
- VS Codeの拡張機能「WSL」をインストール。
- 移動したディレクトリを開き、編集。
- ファイル保存時にブラウザが自動更新されるようになった。
