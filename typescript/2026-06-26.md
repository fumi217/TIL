### TypeScriptのインストール
- [サバイバルTypeScript - 開発環境の準備](https://typescriptbook.jp/tutorials/setup)を参照してインストール。
- Node.jsは、[progate - Node.jsのインストール](https://app.path.progate.com/tasks/PuSZdMDZJY_cksKGNxs4b/preview)でインストール済。
  - インストール先はUbuntu (WSL)。PowerShellにはインストールしていないため、ターミナルを開く際はWSLを選択すること。
  - Ubuntu（WSL）ではLinux環境の、PowerShellではWindows環境のコマンドを実行する。

- インストール時のコマンドはちんぷんかんぷんだが、今は深追いしないこととする。

#### インストール時のエラー奮闘記

- `npm install -g typescript` =>  
  - `npm`：Node.jsのパッケージ（≒ライブラリ）を管理するシステム。
  - `-g`：global。どのフォルダにいても使える場所にインストール。
```
added 1 package in 2s
npm notice
npm notice New major version of npm available! 10.9.0 -> 11.17.0
npm notice Changelog: https://github.com/npm/cli/releases/tag/v11.17.0
npm notice To update run: npm install -g npm@11.17.0
npm notice
```

- `tsc -v` => <span color="#ff0000">以下のエラー</span>
  - `tsc`コマンド（TypeScript Compiler）：  
  TypeScriptで書かれたコード（.ts）を、ブラウザやNode.jsで実行できるJavaScriptコード（.js）に変換（コンパイル・トランスパイル）する。
  - `-v`（version）：現在のバージョンを確認する。（`node -v`等）
```
Command 'tsc' not found, but can be installed with:
sudo apt install node-typescript
```

- `npm root -g` =>
  - npmがグローバルパッケージを保存しているディレクトリを表示する。
```
/home/Ubuntuのユーザー名/.nodenv/versions/22.12.0/lib/node_modules
 └ home: Ubuntu（Linux）に入るためのパス。
```
- `echo $PATH` => ずらっと長いパス名 => 
- `nodenv rehash` => 
  - `nodenv`：Node.jsのバージョン管理ツール。
  - `rehash`：コマンドを探すための索引（ハッシュテーブル）を作り直す。
  - 今回は、nodenvに「新しいコマンド（tsc）が増えたから認識して」と命令（nodenvのshimsフォルダにtscを追加し、コマンドとして認識させる）。
- `tsc -v` => `Version 6.0.3`😊

---
**なぜ tsc が使えなかったか？**
- コマンドを使うには、インストールした場所をPATHに登録する必要がある。
- PATHとは「コマンドを探しにいく場所のリスト」。nodenvは新しいコマンドが増えたとき、自動では気づかない仕組みになってる。
---
**まとめ**
- インストールはできていたが、nodenvが気づいてなかった。rehashで気づかせた。
```
tsc コマンドを打つ
↓
PATHのリストを順番に探し、nodenvのshimsフォルダを見にいく
↓
（rehash前）tscがない！→ Command not found
（rehash後）tscがある！→ 実行できる
```
