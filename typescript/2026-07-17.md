#### 名前つきインポート
- `import {関数名} from "ファイル(等)"`（`{}`で関数名を囲む）
- 外部ファイルやライブラリから、特定の機能や関数等を取り出すために使用する。

インポート元のファイルやライブラリとセットで見ると分かりやすい。  
例：import { LikeButton } from `"./like-button"`  

`like-button.tsx`では、関数`LikeButton`をエクスポートしており、インポートでこれを受け取っている。
```
export function LikeButton() {
    const [count, setCount] = useState(999);

    const handleClick = () => {
        setCount(count + 1);
    }

    return <button className="like" onClick={handleClick} type="button">{count}</button>;
}
```

#### 拡張子の記載要否
React(Vite)においては、ファイルの種類によって記載要否が異なる。

- `.tsx` `.ts`：拡張子は省略<u>**した方が良い**</u>。
  - ツールが、`.tsx`や`.ts`などの候補を自動で探してくれるため。

- `.css`：拡張子は<u>**記載必須**</u>。
  - 拡張子がない＝JS系のファイルと認識されてしまうため。

#### パスとベア指定子
参照箇所が異なる。

- import {xx} from `"./like-button"`;
  - 相対パス。指定した通りに探索。
- import {xx} from `"react"`;
  - ベア指定子。`node_modules`内を探索。
  - 例：`node_modules/react/`フォルダの中から`package.json`の`main`/`exports`部分が指すファイル（`index.js`）を参照している。
